ACS Field Tools for iPhone and iPad

ACS Field Tools is the panel checkout app used by technicians and contractors of Automation & Control Systems LLC. It checks the I/O of Allen-Bradley Logix panels, sets up PowerFlex drives, and files the checkout reports with ACS.

Get help

Email josh@acsllcms.com with the app version shown at the top of the project screen and what you were doing when the problem happened.

What you need

  • An iPhone or iPad with a USB-C Ethernet adapter
  • The panel's controller, remote I/O adapter or drive on the same wired network
  • An access key from ACS to load the project list and file reports

Common questions

Nothing shows under "On the cable". Check that the Ethernet adapter is plugged in and has an address on the panel's network (Settings › Ethernet), and that Local Network access is on for ACS Field Tools (Settings › Privacy & Security › Local Network).

The project list is empty or says the key does not match. Open "ACS report upload" at the bottom of the project screen, re-enter the address and access key from ACS, and tap Save. The key is 48 characters.

I finished a project with no internet. The reports wait under "Finished projects" and are sent the next time the app is open with a connection.

A new module or drive has no IP address. Use the BOOTP server on the I/O Checkout Connect page, or the step-by-step keypad instructions on the Drive Setup Connect page.
